# Student Hub 🎓

A student-focused learning platform designed to make studying easier, more organized, and more accessible.

Student Hub brings together academic resources, an AI-powered tutor, quizzes, study planning, and learning progress in one place — helping students learn at their own pace.

🔗 **Repository:** [github.com/husain651/studenthub](https://github.com/husain651/studenthub)

---

## 📖 About the Project

Student Hub is an educational platform designed primarily for students in Classes 9–12, including matriculation and intermediate students.

The platform aims to simplify the learning experience by providing students with organized educational resources, personalized academic assistance, and tools to manage their studies.

The initial launch will focus on **Class 9 Punjab Board students**, with plans to expand to other Pakistani and international curricula.

## ✨ Features

### 📚 Curriculum-Based Learning
- Organized subjects, chapters, and topics.
- Curriculum-specific learning resources.
- Structured academic content for students.
- Support for multiple educational boards and curricula.

### 🤖 AI Study Tutor
- AI-powered academic assistance.
- Context-aware explanations based on subjects and topics.
- Support for English and Urdu.
- Helps students understand concepts and learn independently.

### 📝 Quizzes & Practice
- Topic-based quizzes.
- Practice questions for revision.
- Track quiz performance and progress.

### 📅 Study Planner
- Organize study sessions.
- Plan academic tasks.
- Manage daily learning goals.

### 📊 Learning Progress
- Track completed topics.
- Monitor learning activity.
- View progress across subjects.
- Bookmark useful resources.

### 🌐 Multilingual Support
- English and Urdu.
- Support for Urdu right-to-left (RTL) layouts.
- Designed to make learning more accessible.

### 🔐 Student Accounts
- Secure authentication.
- Individual student profiles.
- Personalized learning experience.

### 🛠️ Admin Workspace
- Manage educational resources.
- Organize subjects, chapters, and topics.
- Review AI-generated content before publishing.
- Manage users and platform content.

## 🎯 Target Audience

- Class 9 students

- Intermediate students (Classes 11–12)

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Node.js (LTS)
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/husain651/studenthub.git
   ```

2. Navigate to the project directory:

   ```bash
   cd studenthub
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the application in your browser at:

   ```text
   http://localhost:3000
   ```

> Note: Backend services, authentication, database integration, and AI functionality may require additional configuration as development progresses.
